# 受限接入与 VPS 故障实验

更新日期：2026 年 10 月 28 日。

0.4 已在两台经用户明确授权的 Ubuntu 24.04 x86_64 测试服务器上完成专用 SSH 接入和受控故障验证。主机地址、密钥、私有清单和实测报告不随仓库发布。管理员部署和制造故障使用独立管理通道；应用 API、模型及采集密钥仍只能只读。

## 安全接入

1. 每台生成独立采集密钥，核对服务器主机指纹，使用专用 `opsark-readonly` 账号。管理员 root 密钥不填入活动采集清单。
2. 根据具体主机、容器、站点和固定路径生成[精确只读策略](../deploy/readonly/README.md)，管理员审核后安装。
3. 账号无 Docker/journal 附加组。公钥、home、策略、入口及 sudoers 由 root 控制，sudo 只允许调用严格查表的 helper。没有给模型或控制台开放任意 Shell。
4. 使用真实独立公钥验证固定命令成功，以及任意命令、Shell 拼接、通用 sudo、写命令、PTY、SFTP、交互 Shell、本地/远程转发、未知密钥和另一台的密钥均被拒绝。
5. 验证策略权限/符号链接/可写父目录拒绝、单机互斥、断线或 guard 被杀后的子进程锁继承、输出和超时预算。只存在用户名或能登录不能替代这些拒绝验收。

本轮每台 12 项实际 OpenSSH 边界检查和 8 项已安装 Linux guard 检查均通过。另以账号本身确认通用 sudo、公钥写入、策略读取和 Docker socket 写入权限均不可用。服务端策略为每台 14 条精确命令；没有修改或重启 SSH daemon。

## 独立实验服务

[实验 helper](../deploy/vps_lab/README.md)由管理员安装和调用，不放入采集策略。它只操作准确命名且带两个所有权标签的 `opsark-lab-api` 容器，以及带专属标记的单个 Nginx 配置。已有同名但不属于本实验的对象会被拒绝。

- 容器发布到 `127.0.0.1:18881`，Nginx 监听 `127.0.0.1:18880`，Host 为 `opsark-lab.invalid`。
- 只检查 `/healthz` 的 HTTP 200 与 `OPSARK_LAB_OK` 正文。
- 容器限制 64 MiB 内存、0.25 CPU、32 PID、无额外能力、非 root、只读根文件系统、无卷或 Docker socket 挂载，日志最多 1 MiB × 2。
- 只增加实验入口，不需要把测试服务暴露到公网。初始化先执行 `nginx -t`，成功后重载；发生失败时交付实际结果，不把命令成功视为业务恢复。

实验实际使用的镜像 ID 保存在私有验收记录中；可变镜像标签不保证以后每次运行得到同一镜像。容器健康模式的 restart policy 为 `no`，重启机器后需由管理员显式重新初始化实验。

## 本轮真实案例

| 阶段 | 实际结果 |
| --- | --- |
| 接入后初始观测 | 两台实际采集系统、工具、Nginx、容器、容量/inode、内存事件及 SSH 日志；站点状态/正文符合 |
| 停止实验上游 | 两台均产生真实 502，API 报告保存 Nginx 连接拒绝、容器停止和失败站点检查 |
| 启动实验上游 | 即时检查回到 200/正文符合；已有观测基线引用保留，完整恢复验收仍未执行 |
| 连续非零退出 | 应用运行 11 秒后退出 42，Docker 实际重启两次后停止；采集到真实计数、退出码及 stdout/stderr，OOM 标志为 false |
| 实验结束 | 重新创建健康实验容器，两台 Nginx 与上游均 200，实际控制台最终即时检查通过 |

本轮生成 16 份 SSH 报告和 2 份观测基线，模型请求为 0。浏览器已对实际控制台确认两台目标、最终报告和 200 检查结果。实验只读报告的 `action.executable` 始终为 false；管理员制造故障和恢复实验服务不属于产品自动处置。

## 已知边界

Nginx 旧错误仍在读取片段中时，当前报告可以保留 `needs_attention`，同时单独显示即时站点检查符合。不能以一次 200 自动宣告根因消除或事件结案；后续需要事件时间关联和持续观察。

其中一台的默认目录占用检查因目录覆盖不完整而失败，已经保留为证据缺口；根分区容量与 inode 已读到。没有为了通过检查去创建假业务目录。磁盘写满、inode 耗尽、真实 OOM、控制台失联后的预授权防御均未在这两台执行。

旧站数据和维护页不再是本轮测试目标；早先维护交接记录保留为历史，不表示这些资产只能保持旧用途。本轮没有恢复旧业务，也没有重装操作系统。扩展故障前继续核对实际授权目标和实验对象所有权。

本次私有验收回执包括安装、SSH 拒绝检查、Linux guard、故障报告 ID 和当前资产记录索引；所有凭据及运行资料均被 Git 忽略。
