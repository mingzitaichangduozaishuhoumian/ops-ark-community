# OpsArk 社区试用

## 先用合成样本

本地样本已在 Windows 和 Ubuntu WSL2 验证。使用本机、uv 和浏览器即可，无需 VPS、SSH、Docker 或模型密钥。

从仓库的 **Releases** 下载试用公告标明版本的源码 ZIP 附件。解压前，用 PowerShell 的 `Get-FileHash -Algorithm SHA256`、Ubuntu 的 `sha256sum` 或 macOS 的 `shasum -a 256` 对下载文件计算摘要，与发行页公布的 SHA-256 比对。一致后解压到新目录，进入含 `pyproject.toml` 和 `uv.lock` 的目录。使用 Git 的人也可以检出公告标明的提交。记下版本或提交号，反馈时可以引用。

首次同步需要联网下载锁定依赖，本机缺少 Python 3.13 时 uv 也可能下载运行时。 [uv 安装说明](https://docs.astral.sh/uv/getting-started/installation/)

在没有 OpsArk 部署变量的新终端内启动，命令适用于 PowerShell 和常见的 Linux/macOS shell。

```console
uv sync --locked --no-dev --python 3.13
uv run --locked --no-dev python -m uvicorn opsark.main:app --app-dir src --host 127.0.0.1 --port 18190 --workers 1
```

看到 `Uvicorn running on http://127.0.0.1:18190` 后，在同一源码目录打开第二个本地终端。用对应的命令读取刚生成的令牌，只在本地控制台的「控制台令牌」输入框内使用。 [本地控制台](http://127.0.0.1:18190/)

PowerShell

```powershell
Get-Content -LiteralPath .\data\access-token
```

Linux 或 macOS shell

```sh
cat ./data/access-token
```

1. 进入「调查工作台」，将数据来源设为「本地样本回放」。在「回放样本」中选择「回放：站点上游与容器端口不一致 · 网站 502」，点击「运行只读调查」。
2. 报告显示「需要关注」和「样本回放」。打开「证据记录」查看采集项，点击「下载客户交接摘要」，确认下载 `opsark-handoff.md`。摘要会说明数据来自合成样本，验收状态显示「待验收」。
3. 试用的报告和访问令牌保存在当前源码目录的 `data/` 下。按 Ctrl+C 停止控制台后，保留这个目录，并在同一源码目录重新执行启动命令。用本地令牌解锁，从「最近报告」打开原报告，再下载一次摘要。试用结束后，按 Ctrl+C 停止控制台。

默认使用手动模式、空 SSH 清单和未配置模型。端口被占用时，可以把命令里的 `18190` 换成空闲端口，同时修改浏览器访问地址。找不到 `data/access-token` 时，先检查启动终端是否报错，以及第二个终端是否位于同一源码目录。遇到依赖下载失败，在可访问所配置包源的网络内重试 `uv sync`。

遇到卡点或走完流程，都欢迎记录你的版本、系统和完成情况。 [提交试用反馈](../CONTRIBUTING.md#提交试用反馈)

## 再试一台隔离 VPS

已验收的试用目标是 Ubuntu 24.04 x86_64、宿主 Nginx 与同机 rootful Docker Compose。通过维护者提供的可信渠道核对私有试用包和镜像摘要，按包内说明或[运行文档](RUNNING.md)部署空清单控制台。然后使用接入向导核对服务器指纹，按[只读入口说明](../deploy/readonly/README.md)登记专用账号，运行预检并选择一个稳定可复现的故障。

建议提交可复现的反馈：安装或接入耗时、预检缺项、报告哪条结论缺少证据、恢复状态是否清楚。客户摘要下载后仍需人工检查内容，公开反馈优先复现于合成样本。不要提交真实日志、主机地址、访问令牌、密钥、数据库正文或内部报告。

首次连接真实目标时保留默认手动模式。确认身份、检查范围和恢复入口后，再单独验收需要变更的动作。Ubuntu 单包补丁、服务激活和其他处置各有独立权限及验证范围；平台与场景边界见[支持矩阵](PLATFORM_SUPPORT.md)。

容器业务恢复后，可在原容器调查报告上运行只读复验。明确失败显示「复验未通过」，超时或证据不足显示「待验收」，登记的检查全部通过才显示「复验通过」。旧复验和交接摘要可分别打开和下载。 [容器业务复验说明](RUNNING.md#容器调查业务复验)
