现有防护的 ignoreip/journalmatch 设置前后相同，两个既有业务实验容器仍运行，演练 SSH unit 最后均已停止。实际浏览器验证两台观察卡片、演练来源、事件证据及“已阅不证明风险解除”。没有模型请求、外部通知、自动封禁或业务配置改动。完整操作和保留边界见[持续观察说明](SECURITY_OBSERVATION.md)。

实机部署发现私有 staging 目录权限被 Docker COPY 保留，已在镜像中明确应用资产的读取/遍历权限；实机 VERBOSE 日志也促成普通密钥审计行与认证结果的区分。当前采集范围只覆盖有限的认证结果，不是完整 Web/网络入侵检测。

另外已将采集锁逐层传给独立 timeout 和 journal 子进程，补充 Linux 杀父/子进程主动关闭多余 fd 的回归。两台实际安装的 reader 也用真实 journalctl 验证：活跃 timeout 持有锁，reader 被 SIGKILL 后子进程仍受独立期限约束，全部终止后锁才释放。测试使用私有锁文件，未干扰正式采集锁。
