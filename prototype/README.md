# OpsArk 流程原型

这是产品规划阶段的离线交互原型，演示数据全部虚构。它不连接 SSH、模型、监控或防护服务，不接收密钥和密码，也不执行系统操作。

## 打开方式

直接用浏览器打开 [index.html](index.html)。页面没有第三方资源或安装依赖，演示状态只保留在当前页面，刷新会重置。

主机表单用于演示前后条件，不会生成新的诊断数据集；四类事件始终来自预置样例。验收页会将登记的 HTTP 状态和正文条件与预置结果比较，其他检查地址显示为未覆盖。

## 建议演示顺序

1. 进入“接入网站”，填写演示主机，完成模拟连接检查、确认依赖和无业务写入的验收设置。
2. 返回“事件工作台”，查看 502 主样例的结论、原始证据、共享依赖与缺失信息。
3. 打开“处置预览”，检查配置差异和执行停止原因。该样例缺少可靠回退点，执行入口不可用。
4. 进入“恢复验收”，切换演示检查结果，确认观察窗口与未覆盖业务仍然显示。
5. 切换磁盘、容器重启与 SSH 事件，比较不同证据和判断边界。
6. 进入“授权策略”，评审观察模式与预授权的示例判定，尝试不可信来源、管理地址、范围不符及过期授权。
7. 下载当前事件的演示摘要，检查其中保留的虚构数据声明与未解决事项。

界面中任何“通过”“恢复”或策略判定只属于演示场景，不代表真实检查结果。

## 验证范围

本阶段验证导航、表单和依赖确认的前后条件、证据展开、策略判定、报告导出及窄屏布局。真实权限、采集、诊断、防护、配置回退与业务恢复需要按[故障验收案例](../docs/ACCEPTANCE_CASES.md)在后续隔离环境验证。

已完成的浏览器检查见[原型检查记录](REVIEW_NOTES.md)。
